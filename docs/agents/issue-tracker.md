# Issue tracker: Local markdown

Issues and specifications for this repository live as Markdown files under
`.scratch/<feature>/`. Engineering skills should create, read, and update those
files directly rather than calling a remote issue tracker.

## Conventions

- Create one directory per feature under `.scratch/`.
- Store the issue or specification as Markdown in that directory.
- Use the canonical triage labels in front matter or a clearly labeled metadata section.
- Treat `ready-for-agent` as ready for implementation.
